# Content and third-party notices

Project-created code, models, textures, animations and sound have editable sources in this repository. Their provenance is the project itself; no content packs are required. A blanket open-source licence for the project's own content has not been selected. This document does not create a new licence grant or claim trademark clearance.

Godot 4.7.2 is distributed under the MIT licence and includes third-party components under their respective licences. The exact installed engine's copyright inventory and full licence texts are preserved in `game/licenses/GODOT_THIRD_PARTY.txt`; the build script copies this file beside each exported executable.

The in-game default font is bundled **Open Sans**, copyright 2020 The Open Sans Project Authors, SIL OFL 1.1. Its notice and the full OFL text are included in that same inventory. Other bundled engine font/library notices are retained, even where the game does not explicitly select them.

Blender, Python, NumPy, FFmpeg and the native validation utilities are development tools, not downloaded game content. They are not bundled with the game executable. See source scripts and evidence for how project assets were generated and checked.
