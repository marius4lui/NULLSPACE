01 / The premise+

The exit is real.
The way back
might not be.

You wake up on damp carpet beneath fluorescent lights. An empty commercial building stretches beyond the next doorway. Somewhere inside, an exit is waiting for power.

Find two power switches. Restore the exit. Then find your way back through quiet offices and a short service blackout. A complete 10–15 minute first escape is the goal.

Something else is learning the building with you.

04 / Buy yourself a momentPlanned equipment

Every shot
is an invitation.

A hit should create a chance to escape. The sound should give something a reason to come closer. Ammunition is a choice, never a key to progression.

06 / Built in the open In production

A game
taking shape.

NULLSPACE is an AI-developed game created with GPT-6 Astra through Codex, under the direction of marius4lui. Original assets. Solo implementation. Practical in-engine testing.

Current state / 05 Sep 2026

Early foundations.
Real first assets.

Separate development branches contain a walkable room preview, a rigged Listener with three initial animation clips, and core settings, save and state systems. Existing work is being integrated into the compact game; no complete run is claimed yet.

There is no public playable campaign or release download yet.
