# Explicit3D texture import correction

Pre-correction native source472df44 and evidence9f438b2 remain intact. This correction only changes import policy/stored resources and authoring verification; no mesh, UV, authored PNG pixel, palette, light, shader or camera appearance setting changed. M4 native material/performance and independent acceptance remain pending.

Cause found: the original23 PNG sidecars retained default2D lossless storage with no mipmaps. A runtime custom material is not a reliable way to trigger editor import detection. The exact4.7.2 importer exposes preset2 as VRAM mode2 plus mipmaps; its normal option1 forces red/green normal compression. [Pinned Godot importer source](https://raw.githubusercontent.com/godotengine/godot/4.7.2-stable/editor/import/resource_importer_texture.cpp). Godot recommends mipmaps for3D sampling and provides compression/normal and roughness filtering options. [Texture importer documentation](https://docs.godotengine.org/en/stable/classes/class_resourceimportertexture.html).

`policy_change.json` records all23 old sidecar hashes, original PNG hashes, unchanged UIDs and exact field changes. `policy_check.json` checks the written policy. Actual exact-Godot headless reimport completed with no script/engine errors (`import.log`); `post_import_policy_check.json` confirms the engine retained that policy. This is not a native launch.

`imported_resources.json` is from actual `CompressedTexture2D.get_image()` after reimport, not inferred from `.import` text:23 readable VRAM-compressed images with all9/10/11 mip levels at512/1024/2048. Normals are `Image.FORMAT_RGTC_RG`21 (BC5); color/packed data are `Image.FORMAT_BPTC_RGBA`22 (BC7). Full stored image data totals46837008bytes. This does not equal whole-scene GPU allocation and is not a frame-cost result. All verifier error lists are empty (`verify.log`).

Base/emission sampler colorspace stays sRGB; ORM, normal and macro stay linear. Normal green is not inverted, nor are RG channels remapped. Godot reconstructs the normal's blue component, so decoded blue error is intentionally irrelevant. Mip0 normal RG sampled mean errors are1.422/1.396 of255 for wallpaper,1.150/1.080 for carpet and1.385/1.379 for ceiling. Sampled basecolor errors are recorded per channel; wallpaper max mean channel error0.702/255. These numbers measure compression, not perceptual quality. Native close/grazing/distance images must still show whether retained microdetail is adequate.

Run commands are in `tools/art/environment/README.md`. The mechanical policy application is idempotent and refuses a missing UID/field; cache files are excluded. Parent requested this bounded correction first, followed by actual same-view comparison and MSAA/scale/material diagnostics before declaring the94ms GPU problem resolved or changing paper artwork further.
