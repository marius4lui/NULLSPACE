## D — Observation-only predator

Use bounded utility selection plus HFSM action execution, explicit evidence memory and portal/room graph. World topology has stable room/portal IDs, endpoint anchors, door transmission/traversal/state/revision, authored observation/search/retreat anchors. Raw SoundEvent true source stays inside propagation; perception emits event/modality/estimated region/position/uncertainty/confidence/time. Visual observations can include observed posture/facing/travel direction. No player-node reference passes into memory/planning/navigation. Freeze last-seen position immediately at occlusion. Planner Intent contains action/anchor/evidence IDs/reason. Failed navigation cannot substitute current player position. Director consumes aggregate health/ammo/progress/death/proximity/timers and emits quiet/encounter eligibility/broad authored roaming weights; no secret target or observation injection. Coarse sector can guide ambience, not exact search.

Vision uses range/FOV then multiple collision rays and exposure accumulator from authored current light/posture/motion; walls always block. Hearing follows positive portal/path distance+door loss, strongest arrival without amplification loops. Muffled sound supplies incoming portal and uncertain reachable region, sampled once/event; reprocessing cannot renew age/refine location. Gunshot arousal is not exact current location. Belief expands plausible routes by time/direction/topology; evidence strength decays separately from normalized room probabilities. Clear only actually inspected space; door memory only when seen/heard. Intercept uses short inferred route horizon. Stagger cancels pending damage; attacks recheck obstruction. Door closing cannot endlessly restart creature animation.

Initial hypotheses: vision10Hz, planner5Hz, belief2Hz, event-driven hearing, safety/movement60Hz; 85degree central cone22m, lit8m walking recognition0.8–1.4s/sprint0.35–0.6s; far dark peripheral crouch below recognition. Relative noise crouch.04/walk.15/sprint.4/door.35/slam.8/pistol2.5/shotgun4; closed door transmission20–35%. Quiet evidence half-life5s; gunshot/visual12–18s; search4–8 anchors typically35–60s with no new evidence. Utility improvement15% and dwell1–2s except immediate safety/hit. Encounter recovery must reconcile local provocation with longer director quiet policy in GAME_DESIGN.md.

Run all10 mandatory scenarios repeatedly, initially20 seeded variants across range/light/doors, plus paired replays with identical observations and changed hidden player route: planner behavior must match. Structural data-access review, then actual independent unscripted game scenarios and full campaigns. Tests cannot prove experiential fairness. Explicitly reject literature recommendations for brief hidden tracking or bias toward actual player position.
