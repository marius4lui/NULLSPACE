# Security

NULLSPACE is in early development and has no supported game release yet. Security reports about the repository, website, workflows or published files are welcome.

Report a vulnerability privately through [GitHub's vulnerability reporting form](https://github.com/marius4lui/NULLSPACE/security/advisories/new). Include the affected commit or URL, the impact, minimal reproduction steps and any suggested fix. Do not include live credentials or unrelated personal data.

Please keep exploit details out of public issues while the finding is being assessed. There is no promised response time or bug-bounty program.

For ordinary website defects, gameplay problems or design feedback, use [Issues](https://github.com/marius4lui/NULLSPACE/issues/new/choose).
